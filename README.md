# Calculadora de IMC (protótipo interativo)

Este protótipo é interativo e roda direto no navegador.

## Como usar localmente

1. Inicie um servidor local:

```bash
python3 -m http.server 4173
```

2. Abra no navegador:

```text
http://localhost:4173
```

3. Preencha peso e altura para ver o resultado em tempo real, ou clique em **Calcular**.
